## Запуск (PostgreSQL + pgAdmin)

_docker compose up -d_

## Остановка контейнеров

_docker compose down_

## Уничтожение контейнеров + volumes (удалит базу из pgAdmin и Postgres!)

⚠ Осторожно!
_docker compose down -v_

Перезапуск всех сервисов
_docker compose restart_

## 🧩 1. Что такое образ (image)

IMAGE = шаблон / чертёж / «исходник» для контейнера.

Пример:
postgres:15 — это готовый набор слоёв для создания PostgreSQL.

Образ содержит:

ОС (обычно minimal Linux)

бинарники

библиотеки

настройки

файловую систему

📝 Образ сам по себе ничего не выполняет.

## 📦 2. Что такое контейнер (container)

CONTAINER = запущенный экземпляр образа.

Это как программа, созданная на основе шаблона образа.

Например:

образ → postgres:15

контейнер → nest-db

У одного образа может быть много контейнеров:

postgres:15
├─ nest-db
└─ test-db

## 🧠 Образ = класс, Контейнер = объект

(аналогия из ООП)

Image — как class Car

Container — как конкретная машина

Ты не можешь удалить класс, пока есть созданные машины.

## 🔗 Реальная связь:

✔ Контейнеры зависят от образов

(контейнер не может существовать без образа)

✔ Образы НЕ зависят от контейнеров

(образ можно иметь без контейнеров)

## 🗑 3. Что можно удалять, и в каком порядке

❗ Правило №1

Нельзя удалить образ, если есть контейнер, созданный из него.

Если попытаешься удалить image(образ):

_docker rmi postgres:15_

и контейнер **nest-db** существует → будет ошибка:

_Error: image is being used by running container_

✔ Правильный порядок удаления:

# 1️⃣ Удалить контейнер

_docker rm <container_name>_

или если он работает:

_docker stop <container_name>_
_docker rm <container_name>_

и потом...

# 2️⃣ Удалить образ

docker rmi <image_name>

## 🔍 4. Как понять, какой образ используется

Посмотреть контейнеры:
_docker ps -a_

Ты увидишь:

CONTAINER ID IMAGE
^^^^^

Например:

nest-db postgres:15

Значит образ postgres:15 используется, удалять нельзя.

## ❓ 5. Как понять, что образ НЕ используется

Найти все контейнеры
_docker ps -a_

Если среди них нет ссылок на образ:

значит образ можно удалить.

## 🧹 6. Как автоматически удалить все НЕнужные образы

docker image prune -a

Он удалит:

образы без контейнеров,

dangling images.

## 📦 2. Управление контейнерами

Показать работающие контейнеры
_docker ps_

Показать ВСЕ контейнеры (включая остановленные)
_docker ps -a_

Остановить контейнер
_docker stop <container_name>_

Запустить контейнер
_docker start <container_name>_

Удалить контейнер
_docker rm <container_name>_

Удалить контейнеры, которые не используются
_docker container prune_

## 📚 3. Управление образами (images)

Список образов
_docker images_

Удалить образ
_docker rmi <image_id>_

Удалить ВСЕ неиспользуемые образы
_docker image prune -a_

## 🗄 4. Управление Volumes (где хранятся данные PostgreSQL)

Показать volume’ы:

_docker volume ls_

Удалить неиспользуемые:

_docker volume prune_
